# پروژه بویلرپلیت
 تو پروه هات خودت رو جلو بنداز

# ویژگی‌ها (Features)
✅ سیستم احراز هویت (Register / Login)
✅ اتصال به PostgreSQL با Connection Pool
✅ راست‌ چین (RTL) با فونت وزیرمتن
✅ طراحی ریسپانسیو با Tailwind CSS v4
✅ Type-Safe با TypeScript


# تکنولوژی‌ها (Tech Stack) 
Next.js, TypeScript, Tailwind, PostgreSQL, pg

# پیش‌ نیازها (Prerequisites) 
Node.js, PostgreSQL

# نصب (Installation) 
دستور npm install

راه‌اندازی دیتابیس - ساخت دیتابیس و .env.local

# اجرا (Running) 
```bash
npm install
```
